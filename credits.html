CREDITS & IMPLEMENTATION

Made with real robot control.

GRIT policy and deployment: mrzuang / GRIT_teleop_deploy. The original model_99000 checkpoint runs through ONNX Runtime Web; physics runs through MuJoCo 3.12 WebAssembly. This is a simulation demonstration, not robot hardware control.

The browser planner adapts the local arena's motion selection and references to JavaScript. It uses measured robot states, physical contacts, and a 60-second round. Browser and native planners are separate implementations; the GRIT model and its observation/action contract are shared.

PICO motion recordings were supplied for this project. Other punch and kick references come from the existing local motion library, including retargeted boxing and LAFAN-derived sequences. Source labels and modifications are retained in the motion bundle. Original motion datasets retain their own distribution terms, including the Ubisoft La Forge Animation Dataset's CC BY-NC-ND 4.0 terms for affected derivatives; the webpage code does not relicense those assets.

G1 robot geometry is derived from the Unitree description included in the GRIT deployment repository. Model and geometry provenance remain with that repository.

Visual direction inspired by the Perceptive Humanoid Parkour interactive demo. Its policy, page code and research claims are not included in this project.

Third-party runtime licenses: MuJoCo · Apache-2.0 · ONNX Runtime · MIT · Three.js · MIT.
